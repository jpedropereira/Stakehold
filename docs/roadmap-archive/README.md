# Roadmap archive

is one of those threads, moved once all of its tasks were done. They are kept as history and are no
longer updated.

Planned work is now tracked in [GitHub Issues](https://github.com/jpedropereira/Stakehold/issues)
and on the [Stakehold Roadmap](https://github.com/users/jpedropereira/projects/1) board.
